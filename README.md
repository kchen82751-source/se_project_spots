## About The Project

For this project Im creating website for Bessie Coleman. This website is a photo gallery website where people can just go there and look at her photo. When u open that site, she has 6 diferent photos including; Val Thorens,Restaurant terrace, An outdoor cafe,A very long bridge, over the forest,Tunnel with morning light, and Mountain house. With profile info on top of those 6 photos. the difficult part about this project is how to adjust the space for the botton of "New Post" and "Edit Profile", so the solution to solce this is to make time with the tutor and help me to adjust the space of those button.

## Technologies Used

The technologies I use with just my double screen laptop with visual studio code downloaded. With HTML, I type the code in every elements for page, image, description, and profile info inorder to set up a complete webpage.For CSS..... I've created classes for images, titles, and descriptions, and set up various CSS rules for different sections of the webpage. For Java Script...... To handle form submission, I need to use a submit event, not a click event by typeing the right text content of element, function, and listener in order to set up new post form submission
